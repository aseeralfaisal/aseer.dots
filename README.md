# Hyprland Dotfiles

A clean dark desktop setup for Hyprland with Waybar Wofi and SwayNC.

![Desktop preview](https://github.com/user-attachments/assets/64026121-ae70-46dd-b7db-f3fe237fd825)

## Hyprland

* Lua config split into input keybinds appearance and window rules
* Smooth animations blur compact gaps and a new Hyprpaper wallpaper
* Output and region screenshots with clipboard support and Gradia actions

## Waybar

* Compact grouped panels for workspaces resources date weather status transfers and power
* Four visible workspaces with a fallback menu for extra workspaces
* Separate download and upload speed items

## Wofi

* Cleaner launcher and power menu with improved keyboard navigation
* Gemini questions from the search field with the Gemini button or Control Return
* Answers shown inside Wofi with clipboard support
* Local API key setup on first use

## SwayNC

* Matching charcoal glass style shared with Waybar
* Violet active states with compact controls and rounded notifications
